# ariexcore-agent-memory

**Multi-layer persistent agent memory** — working, episodic, semantic + trajectory learning.

Trending: agent-memory, long-term context, RAG-free memory systems (Oct 2026).

## Layers
| Layer | Lifetime | Purpose |
|-------|----------|---------|
| Working | Turn/session | Active tokens |
| Episodic | Task/project | Action trajectories |
| Semantic | Long-term | Distilled facts/skills |
